# E-Waste Saathi — Launch MVP

Built from the supplied JanVoice AI project as a separate frontend MVP.

## Run
```bash
cd frontend
npm install
npm run dev
```

## Build
```bash
npm run build
```

The current MVP keeps the original Spring Boot backend in the repository, but the collector experience is frontend-first so it can be launched quickly. AI identification is represented by the demo workflow; connect it to the existing Gemini service before presenting it as a live AI classification API.

## Main demo flow
Dashboard → Scan E-Waste → AI Result → Weight → Fair Price → Create Digital Lot → Recycler → Earnings.
